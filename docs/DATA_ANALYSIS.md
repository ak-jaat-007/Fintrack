# FinTrack — Data Analysis Notes

The generated dataset contains 1,800 transactions covering 12 months from 2025-10-01 through 2026-09-30.

Current EDA output is in `analysis/outputs/`:

- `monthly_summary.csv`
- `category_summary.csv`
- `weekday_summary.csv`
- `expense_outliers.csv`
- `insights.txt`
- `monthly_income_expense.png`
- `category_spend.png`

The analysis uses Pandas and includes monthly cash-flow analysis, category contribution, weekday/weekend comparison, and IQR-based outlier screening.
